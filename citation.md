# How to Cite CRYSS

If you use CRYSS, CRYSS DOE, or NODES in academic work, publications, theses, or technical reports, please cite the project using the following reference:

**Smith, A. A. (2026). CRYSS: Crystallisation Research & Yield Simulation Suite (Version 1.0).**  
https://cryss.co.uk

## BibTeX

```bibtex
@misc{cryss2026,
  author       = {Smith, Alan A.},
  title        = {CRYSS: Crystallisation Research \& Yield Simulation Suite},
  year         = {2026},
  version      = {1.0},
  url          = {https://cryss.co.uk},
  note         = {MIT Licensed}
}
```

## Additional Modules

If referencing specific modules:

- **CRYSS DOE** — Design of Experiments engine for crystallisation workflows  
- **NODES** — Numerical Optimisation, Diagnostics, and Eutectic Solver

You may cite these individually or collectively as part of CRYSS.
