CRYSS v1.0 Executable Distribution
==================================

This folder contains the packaged CRYSS v1.0 executable.

Files included:
- CRYSS.exe           Main application executable
- LICENSE             MIT License text
- citation.md         Human-readable citation guidance
- CITATION.cff        Machine-readable citation metadata

How to use:
- Double-click CRYSS.exe to launch the application.
- If Windows shows a security warning, choose "More info" and then "Run anyway" only if you trust this release.

How to cite:
- See citation.md for the recommended citation format.
- CITATION.cff is included for citation-aware tools and GitHub integration.
